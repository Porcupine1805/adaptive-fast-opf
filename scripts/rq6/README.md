# RQ6 pipeline

1. Put the DB9 per-series files in `data/DB9/`.
2. Compile Java with `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1`.
3. Install optional dependencies with `pip install -r requirements-rq6.txt`.
4. Run from the repository root:

```powershell
python scripts/rq6/rq6_coordinator.py
python scripts/rq6/generate_sector_labels.py
python scripts/rq6/rq6_clustering.py
```

Outputs are written to `results/rq6/` and are ignored by Git.

The former `sector.py` utility is intentionally excluded because it depended on
an external authenticated service. Sector labels should be generated by the
deterministic local script included here or supplied as a documented dataset.
