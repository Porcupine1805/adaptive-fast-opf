# Project structure and ownership

## Primary implementation

- `src/benchmark/java/OPF_Miner_Original.java`: reference OPF implementation.
- `src/benchmark/java/FOMAblationFlags.java`: common implementation for all
  current FastOPF factorial configurations.
- `src/benchmark/java/GenerateFOMHypothesisDatasets.java`: deterministic
  mechanism-probe generator.
- `src/benchmark/java/FOM.java`: original delivered FastOPF executable,
  retained for provenance but not used for fair factorial comparisons.

## Experimental workflows

- `scripts/benchmark/`: timing only; never enables canonical serialization.
- `scripts/validation/`: canonical output and semantic equivalence.
- `scripts/preprocessing/`: deterministic dataset conversion/concatenation.
- `scripts/analysis/`: figures and manuscript-support generation.
- `scripts/rq6/` and `src/rq6/java/`: downstream DB9 clustering experiment.

## Evidence tiers

- `results/reference/current-probes/`: results generated by the latest BM/WB
  implementation. These are targeted probes, not a complete benchmark matrix.
- `results/reference/historical/`: accepted earlier HJ/OPF summaries and
  historical ablations. Do not use these as current BM/WB measurements.
- `results/reference/rq6/`: compact outputs from the DB9 clustering pipeline.

## Legacy policy

Files under `legacy/` or `src/benchmark/java/legacy/` explain historical
results. They are excluded from primary claims and must be identified as
legacy when cited.
